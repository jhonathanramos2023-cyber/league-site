## 🚨 PROBLEMAS DETECTADOS QUE DEBES CORREGIR

### PROBLEMA 1 — Skins: Falta el efecto lightbox/modal al hacer click
**Lo que hay:** Las skins se muestran en grid como tarjetas estáticas.
**Lo que debe pasar:** Al hacer click en cualquier skin, debe abrirse un **modal/lightbox cinematográfico** que muestre:
- La imagen de la skin en MÁXIMA resolución (splash art completo)
- Nombre de la skin en grande
- Precio en RP si está disponible
- Botón de cerrar con animación
- Transición de entrada: la imagen hace zoom-in desde la card original (shared element transition con Framer Motion)
- Fondo: overlay negro 90% de opacidad con blur
- Click fuera del modal → cierra con animación de zoom-out

```jsx
// Implementar con Framer Motion AnimatePresence
import { AnimatePresence, motion } from 'framer-motion';

// El modal debe usar layoutId para conectar la card con el modal (shared element)
<motion.div layoutId={`skin-${skin.id}`}>
  <img src={skinImageHD} alt={skin.name} />
</motion.div>
```

## 🖼️ SISTEMA DE IMÁGENES EN ALTA RESOLUCIÓN

### API Principal: DataDragon (Riot Games Oficial)

```javascript
// OBTENER VERSIÓN ACTUAL PRIMERO (siempre):

  .then(r => r.json())
  .then(v => v[0]); // Ejemplo: "14.24.1"

// SPLASH ART COMPLETO (máxima calidad ~1920x1080):
const splashFull = `https://ddragon.leagueoflegends.com/cdn/img/champion/splash/${championId}_${skinNum}.jpg`;

// ÍCONO DE HABILIDAD:
const abilityIcon = `https://ddragon.leagueoflegends.com/cdn/${version}/img/spell/${spellId}.png`;

// ÍCONO PASIVA:
const passiveIcon = `https://ddragon.leagueoflegends.com/cdn/${version}/img/passive/${passiveImage}`;

// ÍCONO DE ITEM:
const itemIcon = `https://ddragon.leagueoflegends.com/cdn/${version}/img/item/${itemId}.png`;

// ÍCONO DE RUNA:
const runeIcon = `https://ddragon.leagueoflegends.com/cdn/img/${runeIconPath}`;

// TODOS LOS CAMPEONES con stats completas:

  `https://ddragon.leagueoflegends.com/cdn/${version}/data/es_ES/champion.json`

// DETALLE COMPLETO de un campeón (skins, habilidades, lore):

  `https://ddragon.leagueoflegends.com/cdn/${version}/data/es_ES/champion/Jhin.json`

// → Contiene: skins[], spells[], passive, lore, blurb, stats, allytips, enemytips
```

```jsx
  const handleMouseMove = (e) => {
    const rect = e.currentTarget.getBoundingClientRect();
    const x = (e.clientX - rect.left) / rect.width - 0.5;  // -0.5 a 0.5

      rotateY(${x * 15}deg)
      rotateX(${-y * 15}deg)
      translateZ(10px)
    `;
  };
  
  const handleMouseLeave = (e) => {
    e.currentTarget.style.transform = 'perspective(1000px) rotateY(0deg) rotateX(0deg)';
  };
  
  return (

      ...
    </div>
  );
```
