## Para usar en Replit Agent / Cursor / ChatGPT / Gemini / Claude

---

> **INSTRUCCIÓN GENERAL:** Construye un sitio web épico, cinematográfico y completamente funcional sobre League of Legends. Este sitio debe superar en diseño, contenido y experiencia al sitio oficial de Riot Games (www.leagueoflegends.com). El sitio debe sentirse como una experiencia de juego, no como una página web genérica.

---

## 🎯 STACK TÉCNICO

- **Framework:** React + Vite (o Next.js si prefieres SSR)
- **Estilos:** Tailwind CSS + CSS custom variables + animaciones CSS puras
- **Fuentes:** Google Fonts → `Cinzel` (títulos épicos), `Rajdhani` (cuerpo, UI)
- **Íconos:** Lucide React
- **Animaciones:** Framer Motion
- **Enrutamiento:** React Router DOM v6
- **Imágenes de campeones:** Usar la API pública oficial de Riot/DataDragon:
  - URL base splash art: `https://ddragon.leagueoflegends.com/cdn/img/champion/splash/{ChampionName}_0.jpg`
  - URL base loading screen: `https://ddragon.leagueoflegends.com/cdn/img/champion/loading/{ChampionName}_0.jpg`
  - URL ícono cuadrado: `https://ddragon.leagueoflegends.com/cdn/14.9.1/img/champion/{ChampionName}.png`
  - JSON de todos los campeones: `https://ddragon.leagueoflegends.com/cdn/14.9.1/data/es_ES/champion.json`
  - JSON detalle de campeón: `https://ddragon.leagueoflegends.com/cdn/14.9.1/data/es_ES/champion/{ChampionName}.json`
  - **NOTA:** Reemplaza `14.9.1` por la última versión disponible en: `https://ddragon.leagueoflegends.com/api/versions.json`
- **Mapas:** Usar imágenes de mapas oficiales vía:
  - `https://static.wikia.nocookie.net/leagueoflegends/images/` (Wiki de LoL)
  - O generar mapas SVG propios detallados en código
- **Paleta de colores:**
  ```css
  --gold-primary: #C8AA6E;
  --gold-light: #F0E6D3;
  --gold-dark: #785A28;
  --blue-magic: #0BC4E3;
  --blue-nexus: #1E90FF;
  ```

## 👥 PÁGINA DE CAMPEONES — `/campeones`

### Funcionalidades:
1. **Filtro por Rol:** Todos / Asesino / Tanque / Mago / Tirador / Soporte / Luchador
2. **Filtro por Región:** Demacia / Noxus / Ionia / Freljord / Islas de las Sombras / Void / Piltóver / Zaun / Shurima / Targón / Bilgewater / Ixtal / Bandle City
3. **Filtro por Dificultad:** Fácil / Medio / Difícil
4. **Barra de búsqueda** en tiempo real
5. **Vista:** Grid (tarjetas) o Lista

### Grid de campeones:
- Cargar todos desde la API de DataDragon: `https://ddragon.leagueoflegends.com/cdn/14.9.1/data/es_ES/champion.json`
- Cada card muestra: splash art, nombre, título, rol (como badge), dificultad
- Animación de entrada staggered (cada card aparece con delay)
- Hover: zoom, brillo, overlay con stats básicas

### Layout:
**Hero del campeón:**
- Splash art a pantalla completa como fondo
- Overlay oscuro gradiente desde abajo
- Nombre del campeón en Cinzel gigante
- Título (ej: "El Amo de las Sombras")
- Rol + Dificultad como badges
- Stats base (HP, Mana, Armor, etc.) como barras animadas

**Tabs de navegación:**
- HABILIDADES | LORE | SKINS | BUILDS | COUNTERS | ALIADOS

**Tab HABILIDADES:**
- Pasiva + Q + W + E + R con íconos desde DataDragon
- Al hacer click en cada habilidad: descripción completa, cooldown, costo de mana, daño
- Animación al cambiar de habilidad

**Tab LORE (Historia):**
Para cada campeón incluir su historia completa escrita de forma inmersiva. Los campeones más importantes con lore extenso:

*(Ver sección LORE COMPLETO más abajo)*

**Tab SKINS:**
- Grid con todas las skins del campeón
- Imagen: `https://ddragon.leagueoflegends.com/cdn/img/champion/splash/{Nombre}_{numero}.jpg`
- Nombre de la skin, precio en RP, fecha de lanzamiento

**Tab BUILDS:**
- Build recomendada por rol
- Items con íconos de DataDragon
- Runas recomendadas con íconos
- Orden de habilidades a subir

## 📖 LORE — HISTORIA DE RUNETERRA Y CAMPEONES

### Historia del Universo

**Runeterra** es un mundo mágico creado hace eones. Existen distintas regiones con culturas, conflictos y campeones únicos. Las fuentes de conflicto principales:
- La **Magia del Rune** (poder primigenio que corrompe)
- La guerra entre **Demacia y Noxus**
- El **Vacío** que amenaza con consumir toda existencia
- Los **Celestiales** que observan y a veces intervienen
