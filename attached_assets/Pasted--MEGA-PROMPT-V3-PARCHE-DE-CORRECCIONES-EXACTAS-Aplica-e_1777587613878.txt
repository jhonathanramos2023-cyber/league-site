## 🚨 CORRECCIÓN CRÍTICA #3 — CARDS DE CAMPEONES: IMAGEN COMPLETA

### El problema visual:
Las cards actuales recortan la imagen (ves solo parte del personaje). La solución es mostrar la imagen completa con aspect-ratio más alto y `object-fit: contain`.

### Solución CSS exacta:
```css
/* Card container — más alta, como las del sitio oficial de Riot */
.champion-card {
  position: relative;
  aspect-ratio: 2 / 3;          /* proporción más vertical */
  overflow: hidden;
  border-radius: 4px;
  cursor: pointer;
  background: #050E1A;          /* fondo oscuro para cuando la imagen no llena */
  transition: transform 0.3s cubic-bezier(0.23, 1, 0.32, 1);
}

/* Imagen — mostrar el torso/cara del personaje */
.champion-card img {
  width: 100%;
  height: 100%;
  object-fit: cover;
  object-position: center 15%;  /* sube el encuadre: muestra cara y torso */
  transition: transform 0.4s cubic-bezier(0.23, 1, 0.32, 1);
}

/* Hover: zoom sutil y desplazamiento */
.champion-card:hover img {
  transform: scale(1.06);
  object-position: center 10%;  /* al hover sube un poco más */
}

/* Gradiente inferior para el nombre */
.champion-card::after {
  content: '';
  position: absolute;
  bottom: 0; left: 0; right: 0;
  height: 60%;
  background: linear-gradient(
    to top,
    rgba(5, 14, 26, 0.95) 0%,
    rgba(5, 14, 26, 0.6) 50%,
    transparent 100%
  );
  pointer-events: none;
}
```

### En React/JSX:
```jsx
const ChampionCard = ({ champion }) => {
  // Usar loading screen art — está mejor centrada en el torso que el splash art
  const imageURL = `https://ddragon.leagueoflegends.com/cdn/img/champion/loading/${champion.id}_0.jpg`;
  // Loading screen art tiene mejor composición: muestra cara + torso centrado
  
  return (
    <motion.div
      className="champion-card"
      whileHover={{ y: -8, scale: 1.02 }}
      transition={{ type: "spring", stiffness: 300, damping: 20 }}
    >
      <img
        src={imageURL}
        alt={champion.name}
        loading="lazy"
        style={{
          objectPosition: 'center 15%'
          // Loading screen arts están diseñadas para verse bien en formato vertical
          // No necesitan tanto ajuste como los splash arts horizontales
        }}
      />
      
      {/* Overlay gradiente */}
      <div className="card-overlay" />
      
      {/* Info del campeón */}
      <div className="card-info">
        <div className="card-roles">
          {champion.roles.map(role => (
            <span key={role} className={`role-badge role-${role.toLowerCase()}`}>
              {role}
            </span>
          ))}
        </div>
        <h3 className="card-name">{getChampionName(champion.id)}</h3>
        <p className="card-title">{champion.title}</p>
      </div>
    </motion.div>
  );
};
```

### Por qué usar Loading Screen en vez de Splash Art:
```
Splash Art (splash/{name}_0.jpg):
→ Imagen horizontal (~1215x717px)
→ Composición diseñada para verse en panorámico
→ En cards verticales se recorta MUCHO

Loading Screen (loading/{name}_0.jpg):  ← USAR ESTA
→ Imagen vertical (~308x560px)
→ Composición perfecta para cards verticales
→ Muestra al personaje de cuerpo completo o torso
→ Es exactamente lo que usa el cliente del juego en la pantalla de carga
```
